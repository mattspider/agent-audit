# CI / GitHub Actions

## Workflow básico

```yaml
# .github/workflows/mcp-security.yml
name: MCP Security Scan

on:
  push:
    branches: [main]
  pull_request:

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run agent-audit
        uses: agent-audit/action@v1
        with:
          path: .
          format: sarif
          severity-threshold: error

      - name: Upload SARIF
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: agent-audit-results.sarif
```

## Alternativa via npx (sem Action)

```yaml
- uses: pnpm/action-setup@v4
- uses: actions/setup-node@v4
  with:
    node-version: 20

- run: npx agent-audit scan --format sarif > results.sarif

- uses: github/codeql-action/upload-sarif@v3
  with:
    sarif_file: results.sarif
```

## GitHub Action (v1.1)

Package em `.github/workflows/agent-audit-action/`:

```yaml
# action.yml
inputs:
  path:
    description: Path to scan
    default: .
  format:
    description: Output format
    default: sarif
  severity-threshold:
    description: Fail threshold
    default: error
```

Publicação da Action como follow-up do MVP CLI.

## Integração com PR checks

- Exit code `2` → check vermelho no PR
- SARIF upload → annotations inline nos arquivos MCP
- Badge no README: `![MCP Scan](https://github.com/.../actions/...)`
